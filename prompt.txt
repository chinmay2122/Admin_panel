1. SUMMARY OF CHANGES MADE IN THE ADMIN SIDE
================================================================================

1. Branding & Identity:
   - Official platform name updated to "ErasStudio®" (formerly iRAS Studio / iras).
   - Typography updated to Poppins (Regular 400 & Semi-Bold 600) as primary font,
     and Century / Serif as secondary editorial font for titles and curatorial headings.
   - Clean, light neutral luxury art aesthetic: Canvas (#FAFAF8), Borders (#E8E8E3),
     Ink (#141413), Soft Sand/Beige display container (#EFECE6).

2. Artworks & Curatorial Metadata:
   - Supported metadata on artworks: Title, Creator, Medium (Art Type), Dimensions,
     Year (e.g. 2026), Location (e.g. Mumbai), Collection / Series (e.g. "Monsoon Studies"),
     Availability ("Available", "For Sale", "Not for sale", "Sold"), Description,
     Price Visibility ("Show Price", "Price on Request", "Hide Price"), and Publication Status.
   - Two-column Artwork Discovery experience:
     * Left: Soft sand/beige rounded frame (#EFECE6, rounded-3xl) with full artwork image.
     * Right: Category/Year tag, Large Serif Title, Creator byline avatar pill,
       Curatorial description, Specifications table with horizontal divider lines,
       Price / "Price on request", and Pill Action Buttons.

3. Community Moderation & Reports System:
   - Dedicated "Reports & moderation" section with tabs: All, Pending, Resolved, Dismissed.
   - Standardized report reasons:
     * Possible copyright infringement
     * Inappropriate content
     * Incorrect artwork information
     * Harassment or offensive content
     * Spam or misleading content
     * Fraud or scam
     * Stolen artwork
     * Other
   - Moderation actions: Dismiss, Hide Content (switches artwork to draft), Remove Artwork,
     Suspend User, and Mark Resolved.
   - Traceable moderation audit trail (moderation_audit_logs).

4. Pro Opportunities & Job Applications:
   - Pro subscription tier ("free", "pro", "elite") on user profiles.
   - Pro-only exclusive jobs, residencies, and master commissions.
   - Strict database trigger preventing non-Pro users from applying to Pro-only jobs.

2. DATABASE SCHEMA CHECKLIST (SUPABASE)
================================================================================

Ensure the following tables and columns exist in your Supabase project:

1. public.profiles:
   - plan text DEFAULT 'free' CHECK (plan IN ('free', 'pro', 'elite'))
   - role text DEFAULT 'User' CHECK (role IN ('Admin', 'User', 'Creator'))
   - status text DEFAULT 'active' CHECK (status IN ('active', 'suspended'))
   - full_name, email, portfolio_url, primary_medium, artist_statement, profile_pic_url

2. public.artworks:
   - title text NOT NULL
   - art_type text (Medium)
   - artist_name text NOT NULL
   - creator_id uuid REFERENCES public.profiles(id)
   - description text
   - image_url text NOT NULL
   - additional_images text[] DEFAULT '{}'
   - price numeric
   - price_visibility text DEFAULT 'Show Price' CHECK (price_visibility IN ('Show Price', 'Price on Request', 'Hide Price'))
   - status text DEFAULT 'Available' CHECK (status IN ('Available', 'For Sale', 'Not for sale', 'Sold'))
   - is_published boolean DEFAULT true
   - year text
   - dimensions text
   - location text
   - collection text
   - is_featured boolean DEFAULT false
   - is_flagged boolean DEFAULT false

3. public.reports:
   - id uuid PRIMARY KEY DEFAULT gen_random_uuid()
   - artwork_id uuid REFERENCES public.artworks(id) ON DELETE CASCADE
   - reporter_user_id uuid REFERENCES public.profiles(id) ON DELETE CASCADE
   - artwork_owner_id uuid REFERENCES public.profiles(id) ON DELETE CASCADE
   - reason text NOT NULL
   - details text
   - status text DEFAULT 'pending' CHECK (status IN ('pending', 'resolved', 'dismissed'))
   - moderation_action text
   - moderation_note text
   - resolved_by uuid REFERENCES public.profiles(id)
   - resolved_at timestamp with time zone
   - created_at timestamp with time zone DEFAULT now()

4. public.moderation_audit_logs:
   - id uuid PRIMARY KEY DEFAULT gen_random_uuid()
   - report_id uuid REFERENCES public.reports(id) ON DELETE SET NULL
   - artwork_id uuid REFERENCES public.artworks(id) ON DELETE SET NULL
   - target_user_id uuid REFERENCES public.profiles(id) ON DELETE SET NULL
   - admin_id uuid REFERENCES public.profiles(id) ON DELETE SET NULL
   - action text NOT NULL
   - note text
   - created_at timestamp with time zone DEFAULT now()

5. public.jobs & public.job_applications:
   - jobs: title, company, type, location, description, requirements, is_pro_only (boolean)
   - job_applications: job_id, candidate_id, cover_letter, portfolio_url, resume_url, status

5. SHARED DESIGN SYSTEM & BRAND IDENTITY RULES
================================================================================

Typography:
- Primary: Poppins (Google Font), weights 400 (Regular) and 600 (Semi-Bold).
- Secondary / Editorial: Century, Century Gothic, or Serif for titles.

Color Palette:
- Canvas / Background: #FAFAF8 (Warm off-white)
- Surface / Cards: #FFFFFF
- Display Container: #EFECE6 (Soft warm sand)
- Ink / Text Primary: #141413 (Deep charcoal-black)
- Ink / Muted: #6E6E69 (Medium neutral gray)
- Ink / Subtle: #8A8A85 (Light neutral gray)
- Border / Clean: #E8E8E3
- Border / Subtle: #F0F0EB
- Accent: #141413 (Pure black for primary buttons)
- Status Badges:
  * Published / Available / Resolved: #EAF2EC bg, #28633B text
  * Pending / Review: #EFEFEF bg, #4A4A48 text (or #FAF5EC bg, #865E16 text)
  * Dismissed / Draft: #F3F3EF bg, #71716D text
  * Rejected / Danger: #FDF3F2 bg, #B83838 text

Tone & Philosophy:
- ErasStudio is an editorial curatorial salon, not a SaaS product or retail e-commerce cart.
- Use phrases like "Express Interest", "Direct connection, not a checkout", "Curatorial inquiry",
  "Considered and respectful".
- Avoid shopping cart icons, "Buy Now" buttons, or generic discounts.
